## What it tests

Decryption `p_i = z_i - b` where `z` is a single additive feedback stage over either the whole section or each parser word: `neighbor` (`z_i = c_i +/- c_(i-1)`) or `chain` (`z_i = c_i +/- z_(i-1)`), lag 1, direction `prev`, the first element of each span unchanged, then a constant offset b = 0..28 subtracted afterwards.
